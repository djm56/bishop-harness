## Adding An Entry

1. Take the next free ID (`CONV-NNN`, zero-padded, never reused).
2. Copy the Entry Template below and fill in every field. Nothing blank — write `n/a` if a field genuinely doesn't apply.
3. Add a row to the Convention Index.
4. Keep `Scope` specific — a path or a glob — so a reviewer can match it against changed files.
5. Set `Status: active`. Retiring a rule means `Status: deprecated` plus a short reason in Rule. Entries are never deleted; the IDs are permanent.

## Conventions

### CONV-001 — Theme hooks: registration only, callbacks live in helpers
- **Scope:** wp-content/themes/your-theme/app/hooks.php (WPEmerge-style theme)
- **Status:** active
- **Rule:** `hooks.php` holds `add_action()` and `add_filter()` registrations with NAMED callbacks, and nothing else. The callback itself — named function or closure — is never defined in `hooks.php`; it belongs in the appropriate file under `wp-content/themes/your-theme/app/helpers/`. New hooks are appended at the END of their section; for project and plugin hooks that means the `External Libraries and Plugins` section, after the last existing registration.
- **Rationale:** The file's own docblock says it plainly: declare the functions in the helpers folder, and only call actions and filters here. Registration stays declarative, callbacks stay testable and easy to find, and section ordering survives.
- **Correct:** `app/helpers/footer.php` defines `function app_action_footer_marker() { echo '...'; }`, and `hooks.php` — at the end of the External Libraries and Plugins section — has `add_action( 'wp_footer', 'app_action_footer_marker' );`
- **Incorrect:** `hooks.php` containing `add_action( 'wp_footer', function () { echo '...'; } );` — an inline closure, and in the wrong section.
- **Reviewer check:** On any diff touching `hooks.php`: (1) reject inline closures and function definitions; (2) confirm each callback is a named function defined under `app/helpers/*.php`; (3) confirm new registrations are appended at the end of the right section rather than dropped into the middle.
